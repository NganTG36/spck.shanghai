# SPCK Shanghai Project

## Overview
The SPCK Shanghai project is a web application that allows users to log in and register. Upon successful login, users are greeted with a welcome message and a fireworks animation.

## Project Structure
```
spck-shanghai
├── index.html          # Displays a welcome message and fireworks animation after login
├── login.html          # Contains the login form
├── register.html       # Contains the registration form for new users
├── css
│   └── style.css       # Styles for the project
├── js
│   ├── login.js        # Handles login logic and displays welcome message
│   └── fireworks.js     # Logic for fireworks animation
└── README.md           # Documentation for the project
```

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` file in your web browser to view the application.
3. Use the `login.html` file to log in with your credentials.
4. If you do not have an account, use the `register.html` file to create a new account.

## Usage Guidelines
- Ensure that you have a valid email and password to log in.
- After logging in, you will see a welcome message along with a fireworks animation.
- For any issues, please refer to the documentation or contact support.
